## API

### ChatLoading Props

名称 | 类型 | 默认值 | 描述 | 必传
-- | -- | -- | -- | --
className | String | - | 类名 | N
style | Object | - | 样式 | N
innerClass | String | - | shadowDOM 类名 | N
innerStyle | Object | - | shadowDOM 样式 | N
animation | String | gradient | 加载的状态形式。可选项：moving/gradient/dots | N
text | String | - | 加载过程展示的文字内容 | N
